
Restaurant Website – Django Project

This is a fully responsive and dynamic Restaurant Website developed using the Django Framework. The project includes a modern UI, complete menu display system, online table booking feature, and a functional newsletter subscription module. It is designed to give a real-world restaurant experience with secure backend operations.

✨ Features

Dynamic Food Menu – Add, update, and manage food categories and items from Django Admin.

Online Table Booking – Users can reserve tables by entering their details; data is securely saved in the database.

Newsletter Subscription – Users receive updates by subscribing with their email; duplicate email validation included.

Fully Responsive Design – Works smoothly on mobile, tablet, and desktop using HTML, CSS, JS, and media queries.

Admin Panel Integration – Manage menu items, table bookings, and subscriber list directly from Django Admin.

🛠 Technologies Used

Backend: Python, Django, Django ORM

Frontend: HTML5, CSS3, JavaScript, Media Queries

Database: SQLite / MySQL

Security: CSRF protection, Django Messages Framework

🎯 Purpose

To build a real-world restaurant website with essential booking and subscription features, and to gain hands-on experience with Django backend development and responsive frontend design
